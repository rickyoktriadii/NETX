# NETX — Network Diagnostic Toolkit

Native Android starter project using Kotlin + Jetpack Compose.

Current real/native features:
- Network connection and transport detection
- Local IPv4 detection
- Real latency probe to 1.1.1.1
- Ping-style reachability test
- DNS lookup
- Public IP lookup
- Diagnostic history
- Light/Dark mode
- GitHub Actions APK build

Next: traceroute, controlled speed test, Wi-Fi details, live latency graph, persistent history and richer diagnostics.
